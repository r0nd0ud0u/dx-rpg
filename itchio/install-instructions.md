**Windows**
1. Download `bundle_desktop_windows.zip` and extract it
2. Run `rpg-adventure.exe` inside the extracted folder
3. Create an account or sign in — you're ready to play

**Linux** (`.deb`/`.rpm` recommended over the AppImage — they install the required
`webkit2gtk-4.1` runtime automatically)
- Debian/Ubuntu: `sudo apt install ./rpg-adventure-desktop-v0.5.8_amd64.deb`
- Fedora/openSUSE: `sudo dnf install ./rpg-adventure-desktop-v0.5.8-1.x86_64.rpm`
- Then launch **RPG Adventure** from your applications menu

**Android**
1. Download the `.apk`
2. Allow "install from unknown sources" when prompted (it's not from the Play Store)
3. Open the downloaded file to install, then launch **RPG Adventure** from your app drawer

**First launch**: create an account or sign in, then start a single-player game solo or
create/join a multiplayer lobby with friends.
