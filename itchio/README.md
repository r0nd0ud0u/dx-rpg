# itch.io page assets

- `cover.png` — 1260×1000 (2× itch's recommended 630×500), generated from the game's actual
  palette/portraits (`assets/img/azrak-ombresang.png`, `assets/img/Elara.png`).
- `screenshot-1-overworld.png`, `screenshot-2-combat.png` — copies of `docs/web-game.png` /
  `docs/fight.png`.
- `screenshot-3-mobile.jpg` — copy of `docs/mobile-game.jpg`.
- `description.md` — page description text.
- `install-instructions.md` — per-platform download/install steps, referencing the asset
  filenames from the GitHub Releases page (currently v0.5.8).

None of this is consumed by the app or its build — it's just staged content for manually
filling out the itch.io project page.
