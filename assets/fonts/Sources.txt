Inter — sources and license (SIL Open Font License 1.1, see LICENSE.txt)

	Variable font (opsz 14..32, wght 100..900), latin + latin-ext subsets, roman and italic.
	Downloaded from Google Fonts (fonts.gstatic.com, Inter v20) and vendored so that
	startup — and offline play — never waits on a network request; see
	`inter_font_face_css` in src/common.rs for the @font-face rules built from these files.

	inter-latin-ext-italic.woff2  — https://fonts.gstatic.com/s/inter/v20/UcCm3FwrK3iLTcvnUwoT9nA2.woff2
	inter-latin-italic.woff2  — https://fonts.gstatic.com/s/inter/v20/UcCm3FwrK3iLTcvnUwQT9g.woff2
	inter-latin-ext-normal.woff2  — https://fonts.gstatic.com/s/inter/v20/UcCo3FwrK3iLTcvsYwYL8g.woff2
	inter-latin-normal.woff2  — https://fonts.gstatic.com/s/inter/v20/UcCo3FwrK3iLTcviYwY.woff2
